# Ongaku Desktop 0.1.10

## 日本語

- モバイル版と調和するシルバー／チャコールの外観に更新しました。
- オレンジの強調を再生操作と再生位置の進捗に絞り、環境設定や通常操作の配色を整理しました。
- 再生ボタンの溝、VUメーターのグレー枠、環境設定のサイドバーを調整しました。
- ライブラリの移動・再接続時の探索と復旧を改善し、移行エラー画面の透過を修正しました。
- ライブラリが見つからないフォルダでは、新規作成の確認後に独立したライブラリを作成します。既存データは保持されます。
- 大規模ライブラリの検索処理とメモリ使用を改善しました。

## English

- Updated the interface with silver and charcoal surfaces that complement the mobile app.
- Reserved orange accents for playback controls and elapsed playback progress, with neutral colors for settings and general actions.
- Refined transport-button grooves, gray VU-meter frames, and the settings sidebar.
- Improved discovery and recovery of moved or reconnected libraries, and fixed the transparent migration-error screen.
- Added confirmation before creating a separate library when no library files are found. Existing library data is preserved.
- Improved search processing and memory use for large libraries.

## 简体中文

- 更新银色与炭灰色界面，与移动版风格保持协调。
- 将橙色强调限定在播放操作和已播放进度，设置与常规操作采用中性色。
- 调整播放按钮凹槽、VU 表灰色边框及设置侧栏。
- 改善资料库移动或重新连接后的查找与恢复，并修复迁移错误界面透明的问题。
- 在未找到资料库文件时，先确认再创建独立的新资料库，并保留现有资料库数据。
- 改善大型资料库的搜索处理与内存使用。
