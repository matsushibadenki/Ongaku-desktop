# M1 再生パリティ終了判定

> 2026-09-05再評価: この文書の実装・自動試験・過去の実機記録は、記載された範囲の証拠です。マイルストーン全体の配布合格を意味しません。未実施の確認項目は[ROADMAPのA6／G3](../ROADMAP.md)で判定します。開発優先順位はROADMAPに一本化します。

> 2026-09-05保存改善: 再生キュー・位置・履歴をライブラリUUID付きの原子的sidecarへ分離した。旧manifestからの移行、別ライブラリ拒否、バックアップ復旧を自動試験し、10万曲で位置保存p95 1.022ms、sidecar 237バイト、全曲manifest書込0バイトをRelease計測した。

M1は、再生機能の有無だけでなく、大規模キューの終端処理とプロセス再起動後の復元まで自動検証できた時点で完了とする。

## 自動ゲート

| 状態 | 試験 | 合格条件 |
|---|---|---|
| [Done] | 1,000曲・連続 | 先頭から999回遷移して全曲を登録順に一度ずつ通過し、末尾の次曲が`nil`になる |
| [Done] | 1,000曲・シャッフル | 決定論的乱数で1,000回遷移し、毎回キュー内の再生可能曲を選び、現在曲を直ちに再選択しない |
| [Done] | プロセス再起動 | 逆順の1,000曲キュー、現在曲、再生位置を保存し、新しいRepositoryとPlayerで同じ状態を復元する |
| [Done] | 音源一時不在 | 外付け／ネットワーク音源が起動時に読めなくても、現在曲、1,000曲キュー、保存済み位置を失わない |
| [Done] | 回帰 | Swift全テスト、macOS製品ビルド、UIテストのコンパイルゲートを通過する |

自動試験は`M1PlaybackMilestoneTests`に置き、通常の`swift test`とM0で追加したGitHub Actionsから毎回実行する。

## 配布候補での確認

| 状態 | 環境 | 確認内容 |
|---|---|---|
| [Later] | 実音源・長時間 | 1,000曲の連続／シャッフルを実時間で再生し、出力機器変更、スリープ、音源ドライブ再接続を含む長時間試験を行う |
| [Later] | 強制終了 | 再生中にプロセスを強制終了し、直近の5秒単位の保存位置とキュー順が復元されることを確認する |

実時間で数日を要する試験はM10のRC耐久試験で再実施する。M1では同一の遷移・永続化経路を決定論的に高速検証する。
