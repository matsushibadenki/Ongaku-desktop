# 現行カタログのJSON解析統合（2026-10-15）

## 変更

`LibraryRepository.decodeDocument` は、以前は `JSONDecoder.decode(SchemaHeader.self, from:)` で全JSONを解析し、現行スキーマなら同じDataを `LibraryDocument` として再度解析していた。ヘッダーが小さくてもJSONの構文解析は全曲を含む。

現行形式では `CatalogEnvelope` の `init(from:)` からヘッダーと本体を同じDecoderで復元する。曲一覧の構文解析を1回にまとめる。Foundationの内部保持形式・ゼロコピー・メモリ削減量は保証しない。旧形式は従来の移行処理へ渡し、未来のスキーマの拒否、未バージョン配列、破損時の精密なエラーとバックアップ復旧の経路を維持する。
