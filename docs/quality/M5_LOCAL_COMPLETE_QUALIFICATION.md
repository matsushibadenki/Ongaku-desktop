# M5 ローカル完全版 終了判定

M5は、主要なローカル移行経路が原本を変更せず、管理コピーのSHA-256一致を検証し、外付けライブラリの切断と再接続を安全に扱える時点で完了とする。

## 自動判定

| 状態 | 経路 | CIでの確認 |
| --- | --- | --- |
| [Done] | 通常ファイル／フォルダ | 対応音声だけをArtist／Album配下へ検証コピーし、同一SHA-256を重複登録しない |
| [Done] | オーディオCD | AIFF原本読み込みを照合し、AIFF／WAV／ALAC／AACへの変換後ファイルを再検証する |
| [Done] | HTTPS URL | 公開HTTPS、標準ポート、MIME、拡張子、上限容量、音声デコードを取り込み前に検証する |
| [Done] | Music.app／iTunes XML | 原本のSHA-256が移行前後で一致し、管理コピー、メタデータ、プレイリスト、再実行時の冪等性を検証する |
| [Done] | 別のOngakuライブラリ | 原本非変更のコピー、スマートプレイリスト、フォルダ、詳細メタデータ、冪等性を検証する |
| [Done] | 共有フォルダ | 原本非変更、チェックサム付きコピー、登録済み判定、再実行時の冪等性を検証する |
| [Done] | Media整理／移動 | dry-run、移動後SHA-256、失敗時ロールバック、異常終了ジャーナル復旧を検証する |
| [Done] | 外付けライブラリ | カタログとMediaを同じルートへ作成し、切断時の選択禁止、ID不一致の再接続拒否、移動後の音源バイト列とSHA-256維持を検証する |

外付けライブラリには非表示の `.ongaku-library.json` を作成し、ライブラリUUIDを保存する。再接続アシスタントは選択先のUUID、Catalog、Mediaを確認してから永続セキュリティスコープ付きブックマークを更新するため、同名の別ライブラリを誤接続しない。
