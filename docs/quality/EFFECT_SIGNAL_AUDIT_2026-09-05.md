# エフェクト信号監査 — 2026-09-05

対象はデスクトップの10エフェクトと最終出力。AVAudioEngineのoffline renderingで実際のApple Audio Unitを実行した。

## 出力経路

プレイヤー（正規化・クロスフェード）→ unity source mixer → 10エフェクト → Peak Limiter → -1 dB trim → ユーザー音量 → 出力変換／デバイス。

- [Done] 有効なエフェクトがある場合に最終sample-peak保護を適用。全OFF時はlimiterをbypassしtrimを0 dBとする。
- [Done] 音量操作で圧縮や歪みへの入力が変わらないよう、ユーザー音量を後段に移動。
- [Done] グラフ再接続後に設定を再適用し、サンプルレート依存の処理を更新。

中間段はFloat PCMで、EQや残響加算による1.0超過を許容する。音色を変える各効果の等ラウドネス化は行わず、最終実信号のピークを制御する。`estimatedGainBoostDB`は参考値であり上限保証には使用しない。

## 残る確認範囲

- [Next] 実曲の音量を合わせた試聴、Flutterの時間変化、実デバイスの変換後の録音、長時間のON/OFF切替。今回の数値測定は左チャンネル中心で、知覚音量・ステレオ像・全パラメーター組み合わせの保証ではない。
- [Next] 96 kHz超では既存の互換性方針を維持し、Space全体と一部効果の残響／遅延枝を無効化する。192 kHzの合格は安全なフォールバックの確認で、全機能が同一に動くことを意味しない。Warmの残響枝は既存同様に接続し、今回の192 kHz測定では有限出力を確認。
- [Later] オーバーサンプリングによるtrue-peak保護と、ステレオ・エイリアシング・知覚音量の定量評価。現在の1 dB余裕はDAC再構成波形の絶対保証ではない。

各シミュレーションは独自EQとApple Audio Unitの組み合わせであり、名前に含まれる実機の測定モデルとの一致を検証したものではない。
