# M6 Apple Music基盤 終了判定

M6は、Apple Musicの認証、加入状態、クラウドライブラリ、通信、地域／アカウント制限を独立した能力として判定し、利用できない機能だけを停止してローカル音源の閲覧と再生を維持できた時点で完了とする。

## シナリオ判定

| 状態 | Apple Music側の動作 | ローカル側の動作 |
| --- | --- | --- |
| [Done] | 権限未決定 | 権限説明と許可ボタンを表示し、カタログ操作を開始しない | 閲覧・検索・再生を継続 |
| [Done] | 権限拒否 | システム設定への導線を表示し、カタログ／クラウド操作を無効化 | 閲覧・検索・再生を継続 |
| [Done] | 権限制限 | アカウントまたは端末の制限を説明し、リモート操作を無効化 | 閲覧・検索・再生を継続 |
| [Done] | 未加入 | カタログ閲覧を維持し、再生を無効化してApple公式の加入導線を表示 | 閲覧・検索・再生を継続 |
| [Done] | 加入済み・クラウド無効 | カタログ再生を許可し、クラウドライブラリ変更だけを無効化 | 閲覧・検索・再生を継続 |
| [Done] | 加入済み・クラウド有効 | カタログ再生と利用者ライブラリ操作を許可 | 閲覧・検索・再生を継続 |
| [Done] | オフライン／通信断 | リモート能力を一時停止し、失敗した検索・読み込み・再生操作の再試行を表示 | 閲覧・検索・再生を継続 |
| [Done] | 地域／アカウント制限 | 対象項目を利用不可として説明し、失敗操作を安全に終了 | 閲覧・検索・再生を継続 |

## キューと失敗処理

- [Done] Apple Musicキューの単項目／複数項目削除、並べ替え、全消去で現在再生中の項目を保護する
- [Done] 検索、ページング、チャート、同期ライブラリ、プレイリスト内容、Store検索、再生、前後移動、キュー選択再生の失敗操作を保持して再試行する
- [Done] HTTP 401、403／404、409／412、429、5xxを認証、地域／利用不可、競合、レート制限、サーバー障害として分類する
- [Done] ネットワーク切断、接続喪失、DNS、ホスト接続、ローミング／データ制限を三言語のオフライン説明へまとめる

## 公開API境界

- [Later] ミュージックビデオのアプリ内映像再生は公開APIと画質制御の実機差を検証してから提供する
- [Later] DRM保護コンテンツの任意オフライン保存は公開APIで保証できないため、MusicKitが提供する再生能力を超えて実装しない

公開API境界の詳細は [ADR-0002](../adr/0002-public-api-and-privacy-boundary.md) を参照する。
