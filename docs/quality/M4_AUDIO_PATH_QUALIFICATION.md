# M4 音質と出力の終了判定

M4は、再生時のサンプルレート、チャンネル、DSP順序、音量正規化、出力フォーマットを同じ実行時データからUIと診断ログへ提示し、その処理が元音源を書き換えないことを自動検証できた時点で完了とする。

## 自動ゲート

| 状態 | 試験 | 合格条件 |
|---|---|---|
| [Done] | 入力フォーマット | 実音声ファイルから44.1 kHz／2 chを取得し、音源と内部処理の値として記録する |
| [Done] | DSP | レジストリ順の有効エフェクト、全体バイパス、有効エフェクトなしを区別して記録する |
| [Done] | 音量正規化 | 曲／アルバム／オフ、実適用ゲイン、計測ピークによる制限の有無を記録する |
| [Done] | 出力フォーマット | `AVAudioEngine`の実ハードウェアフォーマットからサンプルレートとチャンネル数を記録する |
| [Done] | 原音非変更 | 実ファイルを読み込み、DSPとピーク制限付き正規化を構成した前後で全バイトが一致する |
| [Done] | UIとログ | 再生設定の「現在の信号経路」と`AudioSignalPath` OSログが同じスナップショットを使用する |
| [Done] | 三言語 | 信号経路、バイパス、原音非変更の説明を英語、日本語、简体中文で表示する |
| [Done] | 回帰 | Swift全テストとmacOS製品・UIテストのコンパイルゲートを通過する |

自動試験は`M4AudioPathMilestoneTests`に置く。診断ログは、エンジン構成、曲間遷移、DSP設定、正規化設定が変わった時に、次の機械可読形式で出力する。

```text
reason=engine-configured source=44100Hz/2ch processing=44100Hz/2ch dsp=equalizer normalization=track:+2.00dB:peak-limited output=192000Hz/2ch sourceMutation=none
```

## 表示上の意味

- 「音源」は`AVAudioFile.processingFormat`から得た入力値。
- 「内部処理」はプレイヤー、ソースミキサー、DSPチェーンへ接続した実フォーマット。
- 「DSP」は全体バイパスを反映した有効モジュールだけをレジストリ順に表示。
- 「音量正規化」は解析キャッシュから求めた実ゲインで、ファイルタグやPCMを保存し直さない。
- 「出力」は`AVAudioEngine.outputNode`の実フォーマットであり、要求値ではない。

## 配布候補での確認

| 状態 | 環境 | 確認内容 |
|---|---|---|
| [Later] | USB DAC／AirPlay／HDMI | 機器切り替え後にログとUIが実フォーマットへ更新されることを複数メーカーで確認する |
| [Later] | マルチチャンネル／空間音声 | 公開APIで利用できるチャンネルレイアウトとフォールバックを実機マトリクス化する |
| [Later] | 長時間DSP | プリセット切り替え、A/B、クロスフェード併用時のCPU、ドロップアウト、熱状態を測定する |

機器選択、passthrough、空間音声の能力判定は、対応ハードウェアを用いるM9の互換性監査でも再確認する。
