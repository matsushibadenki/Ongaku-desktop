# アプリ音声のノード経路 — 2026-11-11

後続の[スピーカー／イヤホン出力](AUDIO_NODE_OUTPUT_2026-11-11.md)で出力専用・録音との分岐・機器選択・元音mute／復旧を追加した。以下は初期実装の記録。

## 実装

SynthのUNGE Swift移植、Canvasのノード／端子／曲線描画、ステレオ遅延線をOngakuへ適用した。UNGEのGraph/Document分離、Command、transactional Batch、revision照合を維持する。原プロジェクトは変更していない。出典・採取時点・ライセンスと適用範囲は[ADAPTATION.md](../../Vendor/NodeRoutingReference/ADAPTATION.md)とsources.jsonに記録した。UNGEのMITライセンスを両Mac製品へ同梱する。

これはSwiftUI + Swift + Objective-C++のネイティブ移植であり、Rustの非同期executorやTauri/wgpuをリンクする構成ではない。Audio Hijackのように処理の経路を接続で決定する操作を実現し、製品全体との機能互換は主張しない。

- アプリ入力、ゲイン、ローパス、ディレイ、2入力ミキサー、メーター、WAV録音。最大16ノード、単一アプリ入力と単一録音先。
- 出力端子→入力端子のクリックで接続。1出力を分岐でき、ミキサーのA/B入力で合流する。接続一覧から切断し、見出しドラッグで移動する。ズーム・スクロール、直列／並列テンプレートを備える。
- パラメーター変更は「適用」で一括確定。ゲイン／フィルター／ディレイはバイパス可能。64操作のUndo/Redo、接続・配置・パラメーターの自動保存と再起動時復元。履歴は起動をまたがない。
- 不正な方向、二重入力、循環、不正パラメーターを候補状態で検証し、失敗時は現状態を保持する。録音開始時に録音ノードの上流をコンパイルし、必要な入力の未接続を拒否。未使用の独立ノードは実行しない。
- 保存シート表示から録音終了まで経路を固定する。入力選択を記憶するが、対象アプリが不在なら別アプリを自動選択しない。開始・停止操作をページ上部に固定する。
- 英語・日本語・简体中文。中立色のノード、配線、パネルを使い、操作説明をinfoアイコンのhelpへ置く。

## 音声処理

Core Audio Tap → コンパイル済みノード → 非同期Float32 WAV writer。SwiftUIは状態と10 Hzメーターだけを受け取り、PCMを保持しない。トポロジカル順の固定スロット、事前確保した遅延線とステレオバッファを使う。音声コールバックでノード生成・メモリ確保・ロック・Swift処理を行わない。

8–192 kHzのFloat32ステレオ（planar/interleaved）を処理し、1回最大4096フレームに分割する。ローパスは1極、ディレイは最大2秒のfractional delay、feedback最大0.9、wet/dry混合。ミキサーはA/B独立ゲイン。元アプリの音は維持するため、ノードの処理結果は録音に反映される。停止後にディレイの残響だけを追加描画する機能はない。
