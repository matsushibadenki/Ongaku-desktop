# M8 転送堅牢化チェックポイント

M8の端末同期は、転送中に利用者が現在位置を確認して安全に停止でき、容量不足や接続断が起きても未検証ファイルをライブラリへ確定しない段階まで進んだ。

## [Done] 今回の保証

| 項目 | 保証 |
| --- | --- |
| 進捗 | MacとiPhoneの送受信で割合、転送済み容量、総容量を表示する |
| 一時停止・再開 | 暗号化された同一接続内で送信側と受信側を同じ制御状態にする |
| キャンセル | 双方の転送処理を止め、キャンセル済みとして失敗と区別する |
| 容量不足 | 受信前に256MBの安全余白を残して判定し、不足時は双方へ通知する |
| 接続断 | 実行中の転送を中断として明示し、未検証ファイルをライブラリへ登録しない |
| 完全性 | ファイルサイズとSHA-256が一致した受信ファイルだけを確定する |
| 表示 | 状態と操作を英語、日本語、简体中文で提供する |

## [Next] 次の境界

- ファイルを固定サイズのチャンクへ分割する
- 完了チャンクとハッシュを永続ジャーナルへ保存する
- アプリ終了・接続断後に不足チャンクだけを再要求する
- 実機で容量不足、破損、Wi-Fi切断、バックグラウンド遷移を検証する

現在の「再開」は同じMultipeer Connectivity接続内での一時停止解除であり、接続をまたぐ再開を意味しない。接続をまたぐ再開はチャンク転送と永続チェックポイントの実装後に完了とする。
