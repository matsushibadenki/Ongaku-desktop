# M7 発見、推薦、共有 終了判定

M7は、チャート、推薦、Ongaku Mixの発見機能が利用でき、ソーシャル機能を使わない利用者の情報を公開せず、共有を選ぶ利用者にも削除・失効・ブロック・監査の安全策を先に提供できた時点で完了とする。

## 発見と推薦

| 状態 | 項目 |
| --- | --- |
| [Done] | 曲、アルバム、プレイリスト、ミュージックビデオ、都市別／ジャンル別チャート |
| [Done] | ホーム、個人向け推薦、最近再生、新着リリース、関連項目、Replay公式導線 |
| [Done] | PCM解析、テンポ、調性、拍位置、ラウドネスを使うOngaku Mixと選曲理由 |
| [Done] | 低電力／高温時の解析停止・復帰、解析キャッシュ、音量正規化とピーク保護 |

## ソーシャル安全性

| 状態 | 安全策 | 保証 |
| --- | --- | --- |
| [Done] | 初期非公開 | 新規・削除後ともプロフィールは非公開、視聴履歴共有はオフ |
| [Done] | 独立した同意 | プロフィールを公開しても、視聴履歴は別に許可しない限り共有対象にならない |
| [Done] | 招待失効 | 招待は既定7日、最長30日で失効し、期限後の承認を拒否 |
| [Done] | ブロック | ブロック時に対象者への保留中招待を即時失効し、新規作成・承認を拒否 |
| [Done] | 監査ログ | 公開範囲、履歴同意、招待、ブロック操作を新しい順に最大200件保存 |
| [Done] | データ削除 | 公開設定、履歴同意、招待、ブロック、監査ログを一括削除し、音楽とプレイリストは維持 |
| [Done] | 未接続時の送信禁止 | 共有サービスを接続していない状態ではソーシャルデータをMac内だけに保存 |

## 公開後へ残す項目

- [Later] 認証・暗号化・レート制限・削除APIを備えた共同編集バックエンド
- [Later] 共同プレイリストのリアルタイム競合解決と絵文字リアクション
